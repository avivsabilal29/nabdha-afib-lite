# rtl

SystemVerilog source for the AFIB-LITE pipeline.

## What belongs here

- Synthesisable `.sv` files: the bandpass stage, the derivative stage, the squaring stage, the
  150 ms moving-window integrator, the adaptive peak detector, the RR series, the feature block,
  and the three-class classifier.
- The top level that connects those blocks and exposes the sample interface and the register map.
- Testbenches and the golden vectors that drive them.
- A package file that holds the fixed-point constants the model generates.

## Coding rules

These rules keep the RTL portable to a standard-cell library, which is what `rtl-synthesis/` needs.

- One clock domain. Derive the 250 Hz sample enable from a counter, and never use a second clock.
- Synchronous reset only.
- No latches. Every branch assigns a default value.
- No vendor primitives, no FPGA-specific macros, no `initial` blocks outside testbenches.
- Integer arithmetic only. Single-cycle multiplies and adds, or a documented multi-cycle schedule.
- No behavioural delays in synthesisable code.

## Interface

| Signal              | Direction | Meaning                                                           |
| ------------------- | --------- | ----------------------------------------------------------------- |
| `sample_data[15:0]` | in        | one ECG sample, 12 significant bits left justified                |
| `sample_valid`      | in        | one pulse per sample                                              |
| `sample_gap`        | in        | the sample stream lost data at this point                         |
| `sample_last`       | in        | end of an evaluation window                                       |
| `class_out[1:0]`    | out       | 0 undecided, 1 normal, 2 needs review                             |
| `confidence[15:0]`  | out       | distance to the nearest decision boundary, in standard deviations |
| `rr_last[31:0]`     | out       | last RR interval in sample counts                                 |
| `beat_count[31:0]`  | out       | beats counted since reset                                         |
| `gap_count[31:0]`   | out       | dropped-sample events since reset                                 |

Results reach the processor over AXI4-Lite. The model in `model/` fixes the exact bit widths and
the fixed-point formats; copy them from there rather than choosing them here.

## Proposed file layout

```
rtl/
|-- afib_lite_pkg.sv      constants and types generated by the model
|-- bandpass.sv
|-- derivative.sv
|-- square.sv
|-- integrator.sv
|-- peak_detect.sv
|-- rr_series.sv
|-- features.sv
|-- classifier.sv
|-- afib_lite_top.sv
`-- tb/
```

Move files around if a cleaner split appears, and update this list when you do.

## Simulation

Two simulators run here without installing anything as root:

```bash
mkdir -p debs debroot
(cd debs && apt-get download iverilog verilator)
for d in debs/*.deb; do dpkg-deb -x "$d" debroot/; done

# compile and run a testbench
debroot/usr/bin/iverilog -B "$PWD/debroot/usr/lib/x86_64-linux-gnu/ivl" -g2012 -o sim.vvp tb/<tb>.sv
debroot/usr/bin/vvp sim.vvp

# lint the SystemVerilog for latches, width mismatches, and undriven signals
VERILATOR_ROOT="$PWD/debroot/usr/share/verilator" \
  debroot/usr/bin/verilator_bin --lint-only -sv <design>.sv --top-module <top>
```

Both are verified on this machine: Icarus 12.0 compiled and ran a design, and Verilator 5.020 linted
a SystemVerilog module with exit code 0. Icarus needs `-B` because it looks for `ivl` and `ivlpp` on
a fixed path, and Verilator must be called as `verilator_bin` directly because its wrapper script
looks for the binary in the wrong place after a relocated install.

Run lint before every commit. A latch that Verilator reports is a bug synthesis accepts in silence,
and it breaks the ASIC port.

## What stays out

- Synthesis scripts and reports. They live in `rtl-synthesis/`.
- Board files, constraints, and bitstreams. They live in `fpga/`.
- Python. The reference model lives in `model/`.
